




# Django Backend - Customer Management

## Setup & Run Instructions

1. Install dependencies:
```bash
pip install -r requirements.txt
```
```
python manage.py makemigrations
```
```
python manage.py migrate
```
```
python manage.py runserver
```
```
http://127.0.0.1:8000/
```


# API Endpoints 
Post Method
```
POST /customer
```
Get Method
```
GET /customer
```
Put Method
```
PUT /customer/<id>
```
Delete Method
```
DELETE /customer/<id>
```
