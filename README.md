# Customer Management System

A simple **Customer Management System** project where businesses can manage their customer information easily.  
This system allows adding, updating, deleting, and viewing customer details efficiently.

## Features
- Add new customers  
- View customer list  
- Update customer information  
- Delete customer data  

## Technologies Used
- Backend: Django / Node.js / Any (based on your project)  
- Frontend: HTML, CSS, JavaScript / React / Angular  
- Database: SQLite / MySQL / PostgreSQL  

## Purpose
This project is created as a practice/learning project to understand how to manage customers and their data in a structured system.
